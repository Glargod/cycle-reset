# Cycle Reset

Local-first countdowns for anything that loops: SuperGrok weekly usage, sleep blocks, chores, project sprints.

Live page: https://glargod.github.io/cycle-reset/

## What it does

- Live ring countdown for the focused cycle
- Multiple named cycles with period, color, and notes
- **Mark reset now** rolls the next stamp forward and writes a local log
- Browser reminders (optional)
- Seed buttons for a SuperGrok week and a 5×90 min sleep block
- Export / import JSON — nothing leaves the browser otherwise

## Grok usage

Paid SuperGrok plans share one weekly pool across Chat, Imagine, Voice, and Build. The real reset stamp is on **Settings → Usage**. This page does not talk to xAI. Paste that stamp into the cycle and the countdown runs locally.

Provider-wide make-good resets (model launches, quality fixes) sometimes clear used percentage without moving your printed weekly stamp. If that happens, tap **Mark reset now** and update the next stamp if Usage changed.

## Privacy

`localStorage` only. No accounts, no telemetry.
