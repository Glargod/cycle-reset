    How this works

    Grok / SuperGrok weekly pool

    Paid SuperGrok plans share one weekly usage pool across Chat, Imagine, Voice, and Build. The exact reset stamp is on Settings → Usage for your account — it is not the same for everyone, and it is not midnight UTC for every account.

    This page does not read xAI. Paste the next reset from Usage, then the ring and reminders run locally.

    Provider-wide make-good resets

    xAI sometimes clears used percentage for everyone (model launches, quality fixes). Those events do not always move your printed weekly stamp. If you get an extra reset, tap Mark reset now and set the next stamp again if Usage changed.

    Recent public ones (community-tracked, not official): 26 Aug 2026 (Bot access + weekly reset), 1 Sep 2026, 5 Sep 2026.

    Sleep cycle seed

    A 90-minute sleep cycle is a planning aid, not a medical device. The seed assumes ~5 cycles (~7.5 h) from a bedtime you pick. Edit freely.

    Privacy

    Everything lives in localStorage on this browser. No account, no server. Export/import if you want a backup.
